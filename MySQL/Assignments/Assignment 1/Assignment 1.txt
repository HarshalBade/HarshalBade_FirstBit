Q3) Create jobs Table with Constraints 
Write an SQL query to create a table named jobs including columns job_id, job_title, min_salary, max_salary. 
Apply constraints: - job_id must be Primary Key - job_title cannot be NULL - max_salary must not exceed 25000 
Ans->
CREATE TABLE jobs(
    job_id INT PRIMARY KEY,
    job_title VARCHAR(20) NOT NULL,
    min_salary DECIMAL(7,2),
    max_salary DECIMAL(7,2) CHECK (max_salary<25000) );

Q7) Create departments Table (Composite Primary Key)  
Composite Primary Key: (department_id, manager_id)
Ans->
 CREATE TABLE departments(
    department_id DECIMAL(4,0),
    department_name VARCHAR(30) NOT NULL,
    manager_id DECIMAL(6,0),
    location_id DECIMAL(4,0),
    PRIMARY KEY(department_id,manager_id) );

Q8) Create employees Table with Normal Foreign Key 
Write an SQL query to create a table named employees including columns: 
employee_id, first_name, last_name, email, phone_number, hire_date, job_id, 
salary, commission, manager_id and department_id.
Apply constraints: 
	- employee_id must be Primary Key 
	- department_id must be a Foreign Key referencing departments(department_id) 
Ans->
CREATE TABLE employee(
    employee_id INT PRIMARY KEY,
    first_name VARCHAR(50),
    last_name VARCHAR(50),
    email VARCHAR(100),
    phone_no VARCHAR(50),
    hire_date DATE,
    jod_id INT,
    salary DECIMAL(10,2),
    commission DECIMAL(10,2),
    manager_id INT,
    department_id INT,
    FOREIGN KEY (department_id) REFERENCES departments(department_id) );

Q9) Composite Foreign Key Implementation 
Step 1: Create department_managers Table 
Create a table named department_managers with following structure:
Composite Primary Key: (department_id, manager_id) 

Step 2: Apply Composite Foreign Key in employees Table 
Alter the employees table so that the combination (department_id, manager_id) 
must exist in department_managers(department_id, manager_id).
Ans->
CREATE TABLE department_managers(
    department_id DECIMAL(4,0),
    manager_id DECIMAL(6,0),
    manager_name VARCHAR(50) NOT NULL,
    PRIMARY KEY(department_id,manager_id) );

ALTER TABLE employee
    ADD CONSTRAINT fk_dept_manager
    FOREIGN KEY (department_id, manager_id)
    REFERENCES department_managers(department_id, manager_id);
