Q4) Write an SQL query to increment the salary of each employee by 10%.
Ans->
 UPDATE employee SET salary=(salary+(salary*0.10));

Q5) Write an SQL query to set EMAIL = 'not available' for employees whose department_id is 80 and commission_pct is less than 0.20. 
Ans->
UPDATE employee SET email='not available'
    WHERE department_id=80 AND commission<(commission*0.20);

Q6) Write an SQL query to set EMAIL = 'not available' for employees who belong to the 'Purchasing' department.
Ans->
UPDATE employee SET email='not available'
    WHERE department_id=(SELECT department_id FROM departments WHERE department_name='purchasing');

Q7) Write an SQL query to update EMAIL = 'not available' and COMMISSION_PCT = 0.10 for all employees.
Ans->
UPDATE employee SET email='not available' , commission=(commission+(commission*0.10));

Q8) Write an SQL query to increase salary by 2000 for employees working in department_id = 60. 
Ans->

Q9) Write an SQL query to delete employees whose salary is less than 5000. 
Ans->
